# Shuffla 넥스트 스텝 전략 — "마케팅 소재 제작 에이전트"로의 전환

> **문서 버전:** 2.0 (v1의 Meta 배포 피벗안은 앱 심사 난이도로 **기각**. 배포 연동 없이 성립하는 방향으로 전면 개정)
> **작성일:** 2026-07-07
> **선행 문서:** [youtube-automation-strategy.md](./youtube-automation-strategy.md)
> **의사결정 기록:**
> - YouTube 자동 업로드: API 할당량(개발자 프로젝트당 일 ~6업로드)으로 보류
> - Instagram/Threads 게시 연동: Meta 앱 심사 난이도로 **진행 안 함**
> - 최종 방향: **플랫폼 API 의존 없는 "소재 제작 에이전트"**

---

## 1. 최종 방향 정의

**"브리프 한 번 → 마케팅 소재 풀 키트"를 만들어주는 대화형 에이전트.**

사용자가 "다음 주 여름 세일 홍보 소재 만들어줘"라고 말하면, 에이전트가 브랜드 컨텍스트를 이미 알고 있는 상태에서:

1. 부족한 정보만 짧게 되물음 (기간, 할인율, 강조점)
2. 채널별 규격 전체 세트를 한 번에 생성 — 카드뉴스(캐러셀), 쇼츠 영상, 스토리(9:16), 피드(1:1), 광고 배너(네이버 GFA/카카오/메타 규격), 썸네일, 홍보 문구 변형 N종
3. 대화로 수정 — "문구 반말로", "더 고급스럽게", "두 번째 장 이미지 바꿔"
4. 규격별 파일로 다운로드 (배포는 사용자 몫 — **플랫폼 API 제로 의존**)

핵심 전환은 **"메뉴에서 고르는 도구" → "말하면 알아서 해주는 직원"**이다. 카드뉴스 만들기, 쇼츠 만들기가 각각의 메뉴인 현재 구조에서, 의도를 말하면 에이전트가 포맷을 선택·조합해주는 구조로 바뀐다.

## 2. 왜 이 방향인가

### 2.1 시장 타이밍

- 2025~2026년 시장의 언어가 "AI 디자인 툴"에서 **"에이전트"**로 이동. 사용자는 템플릿 에디터를 배우고 싶어하지 않고, 결과물을 시켜서 받고 싶어함
- 퍼포먼스 마케팅에서 소재는 **소모품**이다. 광고 피로도(creative fatigue) 때문에 같은 광고 세트에도 주 단위로 신규 소재가 필요 → 단발성 제작이 아니라 **반복 구독 수요**
- 대행사 소재 외주 단가: 배너 세트 건당 수십만 원, 상세페이지 30~100만 원, 영상 소재 50만 원+. AI로 언더컷할 여지가 큼

### 2.2 배포 연동 없이도 성립하는 이유

v1 전략(배포+성과 루프)은 플랫폼 API 승인이 전제였다. 소재 제작 에이전트는 **승인받을 대상이 없다**. 산출물이 파일(이미지/영상/zip)이므로 플랫폼 정책 리스크 제로. 성과 루프는 사용자가 성과 좋았던 소재를 "이런 스타일로 더"라고 대화로 알려주는 것으로 대체 — 완전 자동은 아니지만 에이전트 UX 안에서 자연스럽게 흡수된다.

### 2.3 Shuffla의 기존 자산이 그대로 엔진이 됨

| 에이전트 구성 요소 | 현재 자산 | 추가 작업 |
|------------------|---------|----------|
| 브랜드 두뇌 | 브랜드 URL 분석, editorPreferences, 참고 이미지 | 브랜드 킷 확장 (로고·컬러·폰트 명시 등록) |
| 이미지 소재 생성 | 카드뉴스 파이프라인 (LLM 카피 + 이미지 합성) | **규격 변형 렌더러** (1:1/4:5/9:16/배너 규격) |
| 영상 소재 생성 | 쇼츠 파이프라인 (스톡+TTS+ffmpeg, 원가 ~80원) | 광고 영상 템플릿 (15초 컷) |
| 오케스트레이션 | Inngest + Vercel Workflow (안정화 완료) | 에이전트 툴 호출 계층 |
| 대화형 UX | 없음 | **신규 — 핵심 개발 대상** |
| B2B 통로 | MCP API 기존재 | 외부 공개 + 과금 |

실질 신규 개발은 **① 대화형 에이전트 계층, ② 규격 변형 렌더러** 두 가지다. 생성 엔진 자체는 이미 있다.

### 2.4 경쟁 구도와 차별점

| 경쟁자 | 방식 | Shuffla의 우위 |
|--------|------|---------------|
| 미리캔버스/망고보드 | 템플릿 에디터 (사용자가 직접 편집) | 에이전트가 대신 만듦 — 학습 곡선 제로 |
| Canva Magic Studio | AI 보조 에디터 (글로벌) | 한국형 포맷(카드뉴스·상세페이지), 한국어 카피 |
| Vcat.ai | URL → 광고 영상/배너 (폼 기반) | 대화형 수정 루프 + 멀티 포맷 키트 + 브랜드 메모리 |
| AdCreative.ai | 배너 대량 생성 (글로벌, $25~/월) | 영상 포함 풀 키트, 한국어, 원가 우위 |

차별화 공식: **에이전트 UX(대화·기억·수정) × 한국형 포맷 × 이미지+영상 통합 키트**. 셋 다 가진 경쟁자는 현재 없음. 단, Vcat 등도 에이전트화를 진행할 것이므로 선점 속도가 중요.

> ⚠️ 경쟁사 현황은 2026년 1월 지식 기준. 착수 전 최신 기능 리서치 필요.

## 3. 타겟과 프라이싱

### 3.1 타겟 세그먼트 (우선순위순)

1. **퍼포먼스 마케터/광고 운영자** — 소재 소모량이 가장 큼(주 단위 갱신). 변형 대량 생성이 킬러 기능. 구독 유지율 최고 예상
2. **스마트스토어/쿠팡 셀러** — 상세페이지·상품 광고 소재. 외주 대비 가격 우위가 명확
3. **소상공인/N잡러** — 현재 고객층. 단순함이 핵심 ("말하면 나온다")
4. **대행사** — 시트당 과금 + API. Phase 3

### 3.2 프라이싱 스케치

소재 "키트" 단위 크레딧 과금 (1키트 = 1브리프의 전체 산출물 세트):

| 플랜 | 월 요금 | 내용 |
|------|--------|------|
| Free | 0원 | 1키트 체험 (워터마크) |
| **Agent Lite** | 29,000원 | 월 10키트, 수정 대화 무제한 |
| **Agent Pro** | 79,000원 | 월 30키트 + 변형 대량 생성(A/B 10종) + 브랜드 킷 3개 |
| **Agency/API** | 290,000원~ | 시트 5개 + MCP/API 호출 + 화이트라벨 |

기존 카드뉴스·쇼츠 플랜은 에이전트 플랜으로 점진 통합 (에이전트가 상위 호환이므로 기존 기능은 에이전트의 "도구"가 됨).

### 3.3 원가

키트 1개(카드뉴스 1 + 쇼츠 1 + 배너 5규격 + 카피 변형) 추정 원가 ~500원 이하 (LLM 다중 호출 + 이미지 생성 + 렌더링). Agent Lite 기준 원가율 ~17% — 현행 마진 구조 유지.

## 4. 실행 로드맵

### Phase 1: 에이전트 MVP — "브리프 → 키트" (1~2개월)
- [ ] 대화형 브리프 인테이크 (챗 UI, 브랜드 컨텍스트 자동 로드)
- [ ] 에이전트 오케스트레이터: 기존 카드뉴스·쇼츠 파이프라인을 도구(tool)로 래핑
- [ ] 규격 변형 렌더러: 1:1 / 4:5 / 9:16 / 스토리 (기존 카드뉴스 산출물 기반)
- [ ] 키트 다운로드 (규격별 zip)
- [ ] 대화형 수정 v1 (문구 교체, 이미지 재생성, 톤 조정)

### Phase 2: 소재 커버리지 확장 (2~4개월)
- [ ] 광고 배너 규격 세트 (네이버 GFA, 카카오모먼트, 메타 광고 규격)
- [ ] A/B 변형 대량 생성 (동일 브리프 → 훅·비주얼 10종)
- [ ] 브랜드 킷 등록 (로고, 컬러 팔레트, 폰트, 금지어)
- [ ] 15초 광고 영상 템플릿 (쇼츠 파이프라인 변형)
- [ ] Agent Lite/Pro 플랜 출시

### Phase 3: 고단가 + B2B (4~8개월)
- [ ] **상세페이지 생성** (셀러 시장 고단가 아이템 — 외주가 30~100만 원 대체)
- [ ] MCP/API 외부 공개 — 외부 AI 에이전트(Claude, GPT 등)가 Shuffla를 "한국형 소재 제작 도구"로 호출하는 B2B 채널. 에이전트 생태계 확산의 수혜 포지션
- [ ] Agency 플랜 (시트, 클라이언트별 브랜드 킷, 승인 워크플로우)

### 유튜브 자동화의 위치
현행 유지 (제작+다운로드). 에이전트의 "채널 운영 도구" 중 하나로 흡수 — "쇼츠 30일 운영해줘"가 에이전트 브리프의 한 종류가 됨. 별도 신규 투자는 Phase 2 이후 판단.

## 5. 리스크

| 리스크 | 심각도 | 대응 |
|--------|:---:|------|
| 에이전트 UX 품질 미달 (수정 대화가 의도를 못 알아들음) | 🔴 | 수정 액션을 구조화된 도구셋으로 한정 (자유 생성 아닌 편집 연산), 베타 코호트 검증 |
| 기존 툴 대비 "왜 에이전트인가" 설득 실패 | 🟡 | 랜딩에서 브리프→키트 시연 영상, 1키트 무료 체험 |
| Vcat 등 국내 경쟁자의 에이전트화 선행 | 🟡 | Phase 1을 2개월 내 출시 — 속도가 방어막 |
| 이미지 생성 품질 (브랜드 톤 일관성) | 🟡 | 브랜드 킷 강제 적용 + 생성 후 자체 검수 패스 |
| 기존 플랜과의 카니벌라이즈 | 🟢 | 에이전트 플랜을 상위 티어로 배치, 기존 유저 업그레이드 경로 설계 |

## 6. 결론

배포 연동이 막힌 상황은 오히려 초점을 명확하게 해준다: **Shuffla의 자산은 배포가 아니라 "한국형 소재를 싸고 빠르게 만드는 엔진"**이고, 시장이 지금 원하는 것은 그 엔진 위에 얹힌 대화형 에이전트다. 카드뉴스·쇼츠 파이프라인, 브랜드 분석, Workflow 인프라, MCP API가 전부 재활용되며, 신규 개발의 실체는 대화형 계층과 규격 변형 렌더러 두 가지다. 2개월 내 "브리프 → 키트" MVP를 출시해 선점하고, 상세페이지와 API B2B로 단가를 끌어올리는 것이 다음 12개월의 뼈대다.
